# geoBoundaries sample data (Kenya)

Files: `KEN-ADM0-simplified.geojson` and `KEN-ADM1-simplified.geojson` (the simplified geometry releases of geoBoundaries gbOpen, build 9469f09, built 2023-12-12), and the API metadata responses saved beside them. Retrieved 2026-11-02 from https://www.geoboundaries.org/api/current/gbOpen/KEN/.

Metadata states: boundary licence "Public Domain" (ADM0 and ADM1), source "RCMRD GeoPortal" (ADM1: "RCMRD GeoPortal, Africa GeoPortal"), year represented 2020, 47 ADM1 units. The licence is taken from the dataset's own metadata and has not been confirmed by a human reviewer or counsel.

Citation requested by the project: Runfola, D. et al. (2020) geoBoundaries: A global database of political administrative boundaries. PLoS ONE 15(4): e0231866. The files are unmodified copies and are kept only as test data for the vertical slice; they are not the canonical source of record.

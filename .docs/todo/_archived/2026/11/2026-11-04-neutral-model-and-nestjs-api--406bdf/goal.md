# Goal

Deliver a NestJS product API and a set of Dryv contracts that serve Mzizi's canonical knowledge for any government system, with Kenya represented fully as records rather than as the schema. The API mostly reads; its only writes are comments, evidence uploads and role-gated admin and review decisions.

## Why it matters

The inherited Python models describe a Kenyan political-finance product. Mzizi must hold African and wider governance history without baking one country's levels, institutions or rules into the database. Success means the legacy models are inventoried and classified, shared provenance and time contracts exist, geography is served end to end as a pilot, a second structurally different country loads as records only, and cleaning, processing and saving into the canonical database remain in the separate services.

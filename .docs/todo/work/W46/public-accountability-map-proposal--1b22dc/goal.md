# Goal

Preserve the public accountability map and international comparison idea as a reviewable planning proposal inside the repository documentation, so that it can be assessed, corrected and, only if the owner directs it, turned into approved work later.

## Outcome and measure of success

The proposal document under the planning guides exists with valid frontmatter, is linked from the planning index, and states plainly that nothing is approved or implemented. Every figure taken from the originating discussion is marked as unverified, and the open questions about where cross-country data would live in the Phase 01 schemas are written down. Success is measured by a clean documentation validation run and by the owner being able to read one document and decide the next step, such as choosing a pilot sector, without needing the original chat.

## Out of scope

Schemas, migrations, seed data, application code, data collection and any claim that the capability is built.

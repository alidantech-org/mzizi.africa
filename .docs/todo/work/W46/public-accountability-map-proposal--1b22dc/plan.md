# Plan

## Approach

Write one proposal document in the planning guides folder, linked from the planning index, and track the writing as a single documentation task. The document defines how public bodies are classified (legal basis tier, function type and four control levers), how money and audit evidence would be attached, how scorecards would separate claimed from verified statements, and how a cross-country comparison layer would avoid unfair rankings and causal overclaims.

## Milestones

First, the proposal and index link are written and validated. Second, the owner reviews the placement against the approved Phase 01 contracts and confirms or corrects it. Third, the Kenyan figures are verified against official sources before they enter any dataset. Any further design or task group is created only when the owner directs it.

## Risks

The classification could be mistaken for an approved schema, so the document repeats its planning status. Unverified numbers could be quoted as fact, so they are flagged. The proposal could overlap existing Phase 01 designs, so its placement table is marked unconfirmed.

# Wave 2: governance institutions and offices from official sources

## Goal
Register Kenya's institutions and offices (ministries, state departments, commissions, county governments and assemblies) from official sources and link their sites.

## Context
Institution names, types and parents must come from a source such as the Constitution, the Executive Order on organisation of government, and official institution lists, not from the legacy seed (40 institutions, no sources). Office holders are personal data and need the privacy review task first. Institutions unlock the ministry site pattern and the subject links between sites and governance records. Read .docs/docs/DATA_INTAKE_PLAN.md, .docs/docs/DATA_ENGINE_STATUS_AND_GAPS.md and .docs/docs/LEGALITY_SAFETY_AND_COMPLIANCE.md first. Work only on develop, record progress in this file and tick items with task check.

## Acceptance checklist
- [ ] Select sources and record licences and assessments.
- [ ] Institution and relationship mappings with valid time and precision.
- [ ] Import institutions and offices only; holders wait for the privacy review.
- [ ] Link sites to institutions through website.subjects.
- [ ] Entity resolution for institutions: deterministic names and registry ids first, fuzzy matches only as reviewed proposals.

# Goal

Deliver the jurisdiction-neutral Dryv contracts and the NestJS product API that follow the completed legacy model inventory (see .docs/docs/audits/LEGACY_MODEL_INVENTORY.md). The NestJS app lives in source/backend/api, the dryv/ folder lives at the repository root, and the API mostly reads canonical data. Its only writes are comments, evidence references and role-gated review decisions.

## Why it matters

Mzizi must hold African and wider governance history without baking Kenya's levels, institutions or rules into the schema. Success means shared provenance and time contracts exist, every legacy domain has a neutral contract, geography is served end to end as a pilot with a read-only database role, Kenya plus a second country load as records only, and cleaning, ingestion and migrations stay in the separate services.

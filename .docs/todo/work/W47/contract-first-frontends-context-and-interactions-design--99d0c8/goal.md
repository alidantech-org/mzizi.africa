# Goal

Plan, in writing and before any product code changes, how Mzizi's frontends, backend context and user interactions will be rebuilt so that every screen, operation, query and behaviour is authored in Dryv contracts, generated by packs, and reached only through generated SDK clients.

Success is measured by documents the owner has reviewed and agreed: a page and address hierarchy for web and the mobile app, a user interaction and trust model (anonymous device-identified likes and views on the web; GPS-bound, fingerprint-deduplicated, content-filtered posts on the mobile app only), a context model for multi-country operation using the Cloudflare country header, the contract authoring model, the Dryv capability plan, and a measured blast radius with a migration order. The old admin and mobile prototypes are recorded as deferred and removed.

This follows the two audits recorded on 2026-11-18 (the frontend critic and the hard-coding and context audit) and replaces the decision that frontend implementation is hand-written.

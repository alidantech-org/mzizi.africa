# Insights and modern interface goal

## Goal

Give the public web and mobile apps the statistics, elections, legislative votes, civic money, tenders, media and search a citizen needs, in a modern interface, and fix the Dryv and data gaps found on the way.

## Success criteria

- Any colour notation works in the theme and reaches Flutter.
- A person can search, browse the hierarchy and open statistics, elections, votes, projects and tenders for a place.
- Missing data is labelled with ways to ask or check the source.

## Scope

In scope: contracts, API reads, web and Flutter screens, dev data. Out of scope: accounts, public like counts, production media storage.

The people this serves are citizens, journalists and researchers who want to understand an area without reading spreadsheets. They should always be told when something is estimated, sample or simply not published.

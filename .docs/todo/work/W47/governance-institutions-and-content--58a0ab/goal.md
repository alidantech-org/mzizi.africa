# Governance, institutions and content goal

## Goal

Let a citizen understand how Kenya is governed from the apps: the arms of government, every public body with what created it and who leads it, the leaders by how they got the seat, explanatory texts, and the law behind each of them. The classification lives in reference data, not in the apps, so the screens stay correct as data grows.

## Success criteria

- The directory, a body, the leaders tree, texts, the legal basis and compare options are served by the API from reference schemes and rows.
- The dev database holds the arms, ministries, commissions, courts, funds, county governments and the elected tree, with Constitution effects and texts.
- Smoke checks and database-backed tests cover each read; `bun run check` is green.

<!-- Observable results that mean the goal is met. -->

## Scope

In scope: the Dryv contracts, the database, the dev seed rows and texts, and the API reads and documents. Out of scope: the screens of the Flutter and web apps, which consume the generated clients, and real photographs or emblems.

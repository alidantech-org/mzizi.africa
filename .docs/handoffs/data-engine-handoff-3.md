## 4. Traps found

Shell state resets between Bash calls (set env and `cd` in the same command; `pkill -f` can kill your own shell). `seed reference` and `seed research` are not idempotent on a database that already has them. Fixture row keys must be unique (a duplicate key silently dropped the legislature classification). Candidate dedup in one run must be by natural key before `add_candidates`. Unchanged candidates are not revalidated: use `fixinvalid.sh` after prerequisites are promoted. Mapping `ref` by code is ambiguous for classification codes shared across jurisdictions: pass a `$ref` object with `where` and `jurisdictionId`. The personal-data scan quarantines records whose field names or values look like phone, email or ID: keep contact fields out of unit and entity records. React drops a prop named `key`. Promote speed is about 15 candidates per second.

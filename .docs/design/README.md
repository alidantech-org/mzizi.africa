# Design documentation

Detailed guides live in six broad topic folders. Each topic README lists the documents it owns. Keep technical references aligned with active code and contracts; when moving or renaming a document, update inbound links in the same change. Do not add another root level document under `.docs/docs/`; add or revise a grouped design guide instead.

- [Architecture](architecture/README.md): lifecycle and migration boundaries.
- [Data](data/README.md): database, filesystem, provenance, identity and place models.
- [Geography](geography/README.md): mobile geography API and neutral geography contracts.
- [Acquisition](acquisition/README.md): source-neutral site structures and website registry design.
- [Operations](operations/README.md): development setup, repository map and checks.
- [Policy](policy/README.md): source collection, privacy, safety and publishing policy.

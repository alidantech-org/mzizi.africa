# ROADMAP — Build trustworthy knowledge

The roadmap is a sequence of outcomes, not a list of dated promises. Task records track implementation. Update this page when priorities or completion gates change.

## 1. Keep the foundations reliable

Maintain root-runner setup and checks, stable Dryv contracts, versioned schemas, safe database boundaries and reproducible local development. Fix broken documentation links as part of moves and contract changes.

## 2. Complete evidence-to-publication workflows

Preserve original artifacts, acquire only under documented policy, produce repeatable extraction results, stage attributable candidates, review them, and publish accepted versions with durable provenance. Recovery and retries must not silently duplicate or overwrite canonical knowledge.

## 3. Build the civic accountability pilot

Implement the reviewed Phase 01 scope across geography, institutions, governance, politics, finance, procurement, civic records, accountability, sources and files. Include PostGIS queries for known areas, coordinate lookup, nearby searches and intersections.

## 4. Connect product surfaces

Have the public site, research dashboard and mobile client consume stable API contracts. Clearly expose evidence, historical context, uncertainty, availability and limitations.

## 5. Review deferred domains deliberately

Phase 02 proposals remain deferred until separately prioritized and reviewed. Moving or documenting a proposal does not authorize implementation.

# Owner order: remove six invented Reference schemas

## Decision

The project owner ordered these schemas removed from the Reference contracts (`dryv/contracts/schemas/mzizi/reference.ts`), until further notice:

- `PatternVersion`, `PatternBinding` and `PatternDependency` (the pattern release, scope-binding and dependency tables);
- `LegalBasisLink`, `GeographyChangeLegalBasis` and `OfficialEntityLegalBasis` (the Reference-owned legal basis link and its Geography and Official bridges).

The owner states that an AI assistant invented this design during earlier schema work and that there is no use case for it. Do not reintroduce these schemas, or fields that point at them, without a new explicit owner decision.

## Consequences made in the same change

- `Pattern` remains in Reference as a stub because it was not named in the order; it has no relations. The owner may want it removed too.
- Fields that pointed at the removed schemas are removed: `legalBasisLinkId` on Governance `Mandates` and on Finance `Funds` and `Debts`, with the Mandates index on it.
- The Reference contract no longer imports Geography, Legal, Official, Source or Filesystem, which removes the cross-file type cycle that forced `referenceSchemas` to be typed `any`.
- The earlier open question in `DEC-REFERENCE-BINDING-LEGAL-BRIDGE-20261113` (how bindings reference Legal) is moot and superseded by this order.
- The no-overlap constraint example for bindings and the pattern-related tasks in group GRP-FAA224D85481 no longer have a target in Reference; the constraint feature itself remains available in Dryv.

## Not changed

Generated artifacts under `source/backend/database/` (generated SQL, Rust models and the `0001_init` migration) were produced from the earlier contracts and still contain the removed tables and columns until the database is regenerated by an authorized step. The approved design inventory in `DEC-MZIZI-REFERENCE-GEOGRAPHY-20261112` is a historical record and was not edited.

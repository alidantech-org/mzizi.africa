# Mzizi UI libraries

Hand-written components the generated screens assemble (`web`: React and Tailwind, package `@mzizi/ui-web`; `flutter`: package `mzizi_ui`). They colour only through the generated theme and hold no contract knowledge; the pack templates in `dryv/packs/app-next` and `dryv/packs/app-flutter` fill their typed props from the Dryv contracts. See `.docs/decisions/DEC-FRONTEND-ASSEMBLY-20261117.md`.

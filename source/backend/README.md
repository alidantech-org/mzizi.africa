# Backend

The backend contains one project: the Python orchestration engine in [`engine/`](engine/README.md). Reusable capabilities are under [`../packages`](../packages/README.md); the NestJS product API is [`../apps/api`](../apps/api/README.md); input schemas are in [`../schema`](../schema/README.md); prepared inputs are in [`../../seed`](../../seed/README.md).

Earlier implementations (the inherited FastAPI service, the old data and database engines, the file and intelligence scaffolds) are archived and non-executable: `.docs/_archives/2026-11-08-rewrite-snapshot/`.

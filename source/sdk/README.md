# Mzizi SDKs

Client SDKs generated by Dryv from the product API contract (`dryv/contracts/apps/api`). Each holds every API operation; a frontend's own contract (`dryv/contracts/apps/{app,web,admin,dev}`) lists the operations it consumes and can present only those. Apps import these packages and never carry or invent client code. Do not edit generated files: change the API contract or the project packs in `dryv/packs/sdk-ts` and `dryv/packs/sdk-dart`, then regenerate.

| Folder | Package | Used by | Contents |
| --- | --- | --- | --- |
| `api-ts` | `@mzizi/api-client` | Next.js apps (`web`, `admin`, `dev`) | server actions, route maps, types |
| `api-dart` | `mzizi_api` | Flutter app (`app`) | feature clients, endpoints, models |
| `ui/web` | `@mzizi/ui-web` | Next.js apps (`web`, `dev`) | hand-written visual components; generated screens assemble them (not generated) |
| `ui/flutter` | `mzizi_ui` | Flutter app (`app`) | hand-written visual components (not generated) |
| `ui/brand` | n/a | brand scripts | icon source and mark |

Imports inside the SDKs are absolute: `#sdk/` in TypeScript (package.json `imports`, distinct from the apps' `#/` alias so both resolve in one build) and `package:mzizi_api/` in Dart.

Regenerate with `bun $DRYV_HOME/source/apps/cli/bin/dryv.ts generate --app api --pack sdk-ts --pack sdk-dart`.
